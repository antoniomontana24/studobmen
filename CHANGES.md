# Что изменилось

Скопируйте содержимое архива поверх проекта (с заменой файлов), затем `npm run build`
(папка `docs/` пересоберётся — старые файлы в ней устарели).

## Дизайн
- Палитра ТПУ (tpu.ru/university/attributes/colors): зелёный #28BE46, чёрный; доп. цвета — жёлтый #FFB600, красный #FF4460, сине-фиолетовый #6573FF. Все токены — в начале `src/styles/styles.css`.
- Шрифт ALS Sirius: `src/assets/fonts/`, подключён через @font-face.
- Текст на зелёных кнопках — чёрный (белый на #28BE46 не проходит контраст). Для зелёного ТЕКСТА на белом — `--green-dark`.
- Иконки: `src/components/Icon.tsx` (линейные SVG, без зависимостей). Все эмодзи и символы ★ ♥ ✕ заменены.
- Мобильная версия: нижняя панель навигации, сворачиваемые фильтры.

## Корзина из каталога
`ListingCard.tsx`: кнопка «Купить / Забронировать / Забрать даром» превращается в «Убрать» (красная), на фото метка «В корзине». То же в `BuyBox.tsx`.

## Вход через ТПУ
- `/login` (`pages/LoginPage.tsx`), `context/AuthContext.tsx`, `api/auth.ts`, `utils/auth.ts`.
- Все страницы, кроме `/login`, закрыты (`RequireAuth` в `App.tsx`). Чтобы закрыть только часть — перенесите нужные `<Route>` внутрь/наружу этого блока.
- `CURRENT_USER` из mock больше не используется в интерфейсе — только `useUser()`.
- **`api/auth.ts` — заглушка** (принимает любой логин ≥3 и пароль ≥4 символов). Проверка пароля ТПУ должна быть на backend; готовый код запроса лежит в комментарии в файле.

## Исправленные баги
- `utils/auth.ts` импортировал несуществующий тип `User` — сборка `tsc -b` падала.
- Класс `.profile` использовался и в корзине, и в кабинете (стили конфликтовали) → в корзине теперь `.cart-profile`.
